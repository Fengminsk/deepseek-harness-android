# Android Shell process ownership

The `android_shell` tool starts a separate native supervisor from the app's extracted library directory. The supervisor must acknowledge startup before the tool accepts a result. A missing library, failed parent-death registration, or missing acknowledgement fails the call without falling back to direct `/system/bin/sh` execution. The shell starts only after the supervisor's acknowledgement channel accepts the startup frame.

The supervisor is a detached session and process-group leader. Its child shell and ordinary descendants remain in that group. Linux `PR_SET_PDEATHSIG` notifies the supervisor if its Node parent dies, including `SIGKILL`; the supervisor sends `SIGKILL` to its group. The direct shell also has a parent-death signal if the supervisor itself dies. The supervisor registers as a child subreaper before launching the shell and waits until `waitpid` reports that all adopted descendants are gone, including descendants that closed standard output and error. This kernel-owned child count avoids an enumeration race and does not depend on Android `/proc` visibility for other app UIDs.

Normal cancellation and deadline still signal the detached group. The tool reports timeout, cancellation, output truncation, and an unconfirmed group signal independently. This process-group mechanism does not confine files or permissions, and a command that creates a new session or group can escape it. Android may kill the entire app process set or the supervisor itself; neither this helper nor a transparent overlay guarantees survival of such a kill.

Run `node --test apps/android/tool/shell-deadline.test.mjs` for host-side routing, acknowledgement, cancellation, and deadline checks. On an isolated emulator, run `apps/android/tool/test-shell-supervisor-device.ps1 -Serial emulator-5582 -NdkDirectory <NDK path> -Adb <adb path>`. The script rejects physical-device serials and non-QEMU targets, cross-compiles the native source for the emulator ABI, then checks closed-ack refusal, ordinary command completion, adoption of a live background child with closed output while its parent lives, and whole-group exit after parent `SIGKILL`. A host build or emulator check does not establish ARM64 phone behavior.
