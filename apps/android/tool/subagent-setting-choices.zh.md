# 子 Agent 设置选择项

原版 `packages/subagent/subagent/src/index.ts` 将 `maxDepth` 与 `maxActiveSubagents` 定义为可实时调整且有边界的整数设置。递归深度默认 1，设为 0 可关闭委派；并行子 Agent 上限默认 8，最小为 1。打包的原版配置结构仍负责校验范围和保存。

Pocket Harness 将每个字段放在独立二级页面。常用递归深度 0–3 和并行数量 1、2、4、8、16 以整行选项呈现；当前 Host 结构拒绝的选项不会显示。同一详情页的文本框可输入其他整数，并按原结构校验。用户未点完成就返回时，原值不变。选择后只写入配置草稿，仍需回到上级配置页保存，并遵循版本与冲突处理规则。

此交互仅用于打包的 `subagent` 命名空间下这两个精确字段。其他插件继续使用配置结构驱动的控件。组件测试覆盖范围过滤、准确草稿值、无效输入和自定义值；真机显示仍待验证。

独立的子 Agent 模型选择页在原版 Settings 描述符报告 `enabled` 或 `allowedModels` 存在用户覆盖时，也提供恢复入口。页面先展示 Host 的继承策略，再只对确有用户覆盖的字段按已观察版本发送 `unset`。存在未保存草稿或尚未解决的冲突时不可恢复；运行时观察结果变化会先关闭确认界面。共享编辑控制器在写入前重新读取配置，结果不确定时保留待核对状态。已有会话记录的模型选择策略不会改变。组件测试覆盖两个字段和单个字段的恢复、本地草稿及外部配置变化；真机行为仍待验证。
