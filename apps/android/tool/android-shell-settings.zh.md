# Android Shell 设置选择项

打包的 Android Host 将 `shellTimeoutMs` 和 `shellOutputLimit` 作为
`android-runtime` 的实时字段提供，因此两个设置都能通过真正的 Settings 描述符
访问。原版结构允许执行超时为 1 至 3,600,000 毫秒，每路输出保留大小为 1,024
至 1,048,576 字节。Shell 工具在获准的命令开始时读取已保存值；修改设置不会改变
已经运行的命令。

“Android 工具 > Shell”二级页面为两项提供带单位和边界的常用选项。各字段页面
也允许输入原版结构范围内的其他整数。共享配置控制器先暂存选择，再按已观察版本
只保存有变化的字段；继承值用 `unset` 恢复。版本冲突或保存回执不确定时保留草稿
供核对。高级 JSON 编辑仍可从高级设置访问。

组件测试覆盖两项选择的一次版本化保存、自定义值校验及过期版本。现有分组编辑
测试覆盖恢复继承值、冲突核对和不确定保存。设备可用时仍需完成真机交互验收。
