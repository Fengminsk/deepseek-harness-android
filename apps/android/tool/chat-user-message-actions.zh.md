# Android 会话中的用户消息操作

DSH 原版的 `MessageIconActions` 在每条用户消息下方放置复制图标和本地时间。Android 在用户气泡下方显示同样紧凑的操作行。直径 44 dp 的圆形复制触区仅写入用户编写的文本块；成功后短暂显示对勾。剪贴板写入失败时，操作仍可重试，并在原处显示错误。旧消息的写入延迟完成时，不会把替换后的消息标记为已复制。

时间来自事件时间戳并按本地时间显示：当天为 `HH:mm`，本年较早日期显示月日，跨年显示年月日。缺少有效正数时间戳的事件不显示时间。运行时上下文、系统提示等非用户记录不带用户操作行，仍可在独立的会话记录页查看。复制操作不会把附件转换为文本。

同目录归属的 `chat_user_message_actions.expected.json` 会话样例记录了用户消息、运行时上下文和助手消息。Flutter 测试覆盖仅用户消息显示操作行、本地日期边界、剪贴板内容与对勾复位、失败后的重试，以及消息替换后的延迟写入。未进行真机测试，因此设备外观和 Android 剪贴板行为尚未验证。
