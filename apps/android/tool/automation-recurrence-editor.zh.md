# Android 自动化重复规则编辑

[English](automation-recurrence-editor.md) | 中文

Android 自动化详情读取并更新原版 Host Schedule 记录。[DSH Schedule](../../../packages/client/ui-schedule/README.zh.md) 使用暂存的规则编辑；Android 的“重复”行现进入二级选择页，提供单次、每天、周一至周五、每周、固定间隔和自定义 Cron。周一至周五提交原版每周规则及星期一至星期五。每周规则另有星期选择页，至少须保留一天。

固定间隔进入独立的数量和单位页面。保存时仍提交 `every_seconds`；整小时、整分钟和秒只是显示与输入选项，最终秒数须介于 60 和 9,007,199,254,740,991 之间。已保存的间隔值无效时会显示待修复状态，不会让详情页崩溃。更换单位会更新预览；点“完成”才把秒数暂存到详情页。从二级页面返回会丢弃该页面的修改。直到详情页点击“保存任务”才会调用 Schedule。

保存沿用 Host 的比较后更新请求；即使紧接着刷新的目录仍返回旧记录，编辑器也保留已确认的提交回执记录。冲突和结果不确定时保留本地草稿供核对。这些交互已有 Flutter 组件测试；手机交互和进程重启行为仍需设备验收。
