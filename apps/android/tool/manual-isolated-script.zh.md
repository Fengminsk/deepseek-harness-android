# 手动隔离脚本运行

「设置 > 手动隔离脚本」是用户主动发起的开发工具，不向模型注册 PTC 或工作流工具。原生 `isolatedManual.prepare` MethodChannel 入口使用独立 Binder 消息送往 `AgentService`；普通 Node／运行时 JSON-RPC 不能构造授权。

## 选择与授权

- 先选择已有会话。访问文件时还必须选择已登记工作区，其目录要等于会话目录，且位于 App 私有运行工作区内。授权只指向该工作区中的一个已有普通文件。符号链接上级、目录授权、任意外部路径和未登记的工作区身份均被拒绝。
- 文件默认关闭。选中文件后默认只读；编辑需单独选择。网络默认关闭，只能填写一个无路径、无端口、已规范化的精确 `https://host`。原生网络代理还会拒绝本地和类似 IP 的目标。
- `AgentService` 在准备时自行读取当前目录，并在准入前再次核对会话、工作区成员关系、目录及文件身份。选择已变化时撤销批准计划，在访客脚本执行前持久记录取消。复核与后续目录变化不能构成原子操作；原生文件代理仍约束每次文件访问。授权范围、脚本、输入、会话、工作区和期限都绑定到新的运行 ID。有文件或网络能力时进入现有原生授权收件箱和 Android 确认框；无能力脚本可以按拒绝全部能力的范围运行。
- 每次授权只供一次运行使用。过期、拒绝、IPC 丢失或进程重启均不会自动重放脚本或扩大范围。

## 结果

页面轮询 `isolatedManual.status`。只有持久化的 `COMPLETED` 终态回执才会展示 `outputJson`；其他终态分别显示。已准入却没有终态回执时标记为「未确认」，进程被杀后也是如此，App 不会自动重试。取消会等待原生控制器收尾，仍须读取最终状态。最近一次运行 ID 保存在本地，以便重新打开页面后核对持久回执。

## 当前边界

这是每次只能授权一个精确文件和一个精确 HTTPS 主机的手动开发入口。通用模型可见 PTC／工作流执行、目录能力授权、任意 SAF／外部工作区以及自动恢复不由此入口提供。
