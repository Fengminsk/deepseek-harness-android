# 聊天中的模型重试状态

Android 聊天记录按重试 ID 与尝试次数解析原版 `llm/retry`、`llm/retry-started`、`step/end` 和 `turn/end` 事件。当前正在运行的回合中，已安排的重试从首次可见时开始倒计时，与 Web 的 `ModelRetryItem` 计时方式一致，无须信任可能使用另一时钟的 Host 时间戳。尝试开始、取消、回合停止或列表行离开可见区域时，动画会停止。新回合运行期间，旧回合未完成的重试只显示静态记录。

简洁的状态行可在原处展开，显示记录的延迟、经现有凭据安全显示策略处理的失败原因及前次尝试。该行不会发起或取消重试。重新打开历史会话仅读取已保存的 Session 事件，不会制造新请求或截止时间。归属本功能的事件夹具与 Flutter 测试覆盖倒计时、尝试替换、取消、敏感信息遮蔽和新回合边界；手机上的计时与生命周期行为尚未验收。
