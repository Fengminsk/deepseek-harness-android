# Android 会话中的助手过程

DSH 原版会话投影将助手步骤中的思考内容放入过程组，并将撰写的回复放在过程组外。Android 阅读流对实时流和已保存会话采用同样的分离方式。思考内容先以一行收起的过程状态显示，点击后在原处阅读已记录的文字。实时步骤只有思考内容时，该行显示带扫光的“正在思考”；没有工具活动时隐藏重复的通用进度行。回复文字到达或流结束后显示“已思考”。回复文字和附件保持原有顺序；长按复制仅提取撰写的回复文字。

归属本功能的 `chat_assistant_process.expected.json` 夹具记录同时包含思考与回复块的助手消息。Flutter 测试核对过程行位于回复复制区域之外、展开前隐藏正文，以及实时文字到达时的状态变化。界面不会推断模型提供方未输出的私有思考内容。真机渲染和动画时序仍待验收。
