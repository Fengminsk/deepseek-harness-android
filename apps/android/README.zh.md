## DSH 迁移基准

Pocket Harness 的目标是在 App 内覆盖完整的 DSH 产品流程，当前预览尚未达到这一目标。原版 [Web 组合](../../packages/bundle/web-app/cordis.patch.yml)、[标准预设](../../packages/bundle/web-app/presets/standard.patch.yml)及所属服务定义需要迁移的行为；保留 Web 资源或提供通用 API 不等于 App 已覆盖。移动端导航可以不同，但功能语义、会话身份、授权、持久化和冲突处理必须与 DSH 对齐。

[迁移清单](tool/parity-manifest.json)记录原版条目及对应的 Android 代码和证据。在仓库根目录运行 `node apps/android/tool/parity-audit.mjs`，检查未分类的源码变化和无效引用。这项清单检查不会执行功能，也不代表功能通过验收。核心组合、App 交互、行为测试和真机验收分别记录，部分实现仍标为部分实现。

DSH 已有[会话工作目录文件树](../../packages/client/ui-sidebar-files/README.zh.md)，以及文本、代码、Markdown、图片、PDF、HTML、Excel 和 Office 的[文档预览](../../packages/client/ui-sidebar-documentpreview/README.zh.md)。当前会话菜单通过原版 [workspaceFiles 服务](../../packages/api/workspace-files/README.zh.md)打开会话文件，保留工作目录、文件权限、版本和变更订阅。目录在同一原生页面中切换，支持面包屑与滚动位置恢复。这与 App 私有文件、SAF 授权及会话附件 ID 是不同入口，各自保留独立授权。

会话资源页集中原版会话工作目录、已记录的文件改动审阅、只读技能目录、按会话筛选的后台任务、基础会话终端及远程网页入口。改动记录使用已保存的回合公告与 Host 摘要；打开页面只读取历史，不创建或恢复 Agent。入口接受远程 HTTP(S) 地址，并在页面打开期间保留最多 30 条记录。网页加载、前进后退和 Cookie 由 AndroidX Custom Tabs 管理；不可信远程网页不进入 App WebView，也拿不到文档桥接。直接输入本地及私有地址会被拒绝。远程网页仍可能重定向访问设备网络中的本地服务；DSH Web 服务依靠独立的认证及请求来源校验，而非这个地址过滤器。桌面分栏／浮动停靠布局和内嵌浏览器控制尚未映射；原生侧栏在核对地址后可打开当前会话的子 Agent 对话，文档预览仍可通过会话文件和文档链接打开。Custom Tabs 行为尚无真机验证。

移动端会话资源工作区以横向滚动标签切换单个全屏资源。资源首次选中时才挂载；切换标签保留已挂载文件位置、浏览器草稿／历史和终端视图状态。关闭标签会卸载视图；关闭终端标签仅卸载视图，不结束 PTY，终端页面另有关闭进程操作，最终清理由 Host 负责。标签类型、顺序与选中项按运行时及会话在内存中保留，重新进入页面时选中资源只读取当前状态，不创建 Agent 工作或新 PTY。未选中的标签重新进入时仍不挂载，直到用户选中。App 进程重启后从资源入口重新开始，不恢复任何工作。桌面分栏／浮动面板与内嵌浏览器控制没有移动端对应实现。

会话中已有的历史工作流事件现在按运行、阶段和成员展示只读层级。分页与增量更新回放原始持久事件，不创建运行，也不激活 Android 上禁用的 PTC 执行器。只有当前父会话的原版目录确认子会话仍挂载且运行时，界面才显示入口；打开时再次校验子会话自身身份、运行状态和连接代际。该导航目前只有主机测试证据。

当前会话的子 Agent 目录现可从侧栏直接打开。目录行必须包含准确的直属父会话与子会话地址；点击后再次通过原版带地址的历史服务核对子会话自身描述。缺失、过期或指向其他父会话的地址不能打开记录。子会话页面覆盖在父聊天页面上，返回时保留父会话草稿和阅读位置。Flutter 主机测试覆盖错误归属、失效核验、断连及返回路径。这里实现的是原生子会话导航；原版停靠侧栏标签页仍未映射，真机行为未验证。

会话文档在专用 Android WebView 内使用原版阅读器资源，导航采用原生悬浮组件。内置资源与绑定会话的读取接口在 Web 访问关闭时也可工作。二进制数据按有限大小分片传输；关闭或取消页面会释放请求、订阅和保留的数据。Markdown 本地图片使用同一会话文件服务和原版媒体大小限制。同一会话内的文档链接打开阅读页，返回时保留来源位置；当前文件的行号链接直接定位，不重新读取文件。跨会话及不支持的资源链接会明确报错。原版 Office 转换器已在主机上使用包内 WASM 引擎，通过会话授权读取、Android profile 的 Gateway 和有上限的 PDF 字节传输，将合成 DOCX 转成 PDF。Android 让每次转换在独立 Node 子进程运行，退出后释放 WASM 内存；这不降低转换期间的设备总内存峰值。真机渲染及内存表现尚未验证。交互式 HTML 预览现读取原版共享 `ui-settings.enabled` 的已确认值：关闭或无法核对时为静态预览；开启后，原版阅读器只在无同源权限的沙箱 iframe 中运行脚本，并经绑定会话读取有数量和大小上限的本地 JS/CSS。切换偏好不重建阅读器。文档 WebView 仍阻止外部 HTTP(S) 资源；交互式 HTML 的真机渲染尚未验收。主机渲染与导航测试不能代替 Android WebView 真机验收。会话终端离开页面后保留，所属 Agent 卸载时关闭；主机生命周期测试不能代替真机进程清理验证。

资源标签使用紧凑字号，并暂停隐藏页面的动画。资源页统一处理路由返回，保留的文件页不会递归拦截返回。文件阅读页返回前不重复打开同一入口。文件浏览器共用 App 的背景氛围，滚动时暂停背景动效。

[Android 配置补丁](runtime/cordis.patch.yml)与[预设暂存](tool/stage-preset.mjs)仍缺少原版终端控制器、完整移动端 VT 渲染器、受进程隔离的 PTC 工作流，以及部分标准预设。原版 Agent 的 `glob`／`grep` 与网页搜索／抓取现已按标准设置组合，但 Android 进程执行与网络行为仍待真机验收。这些是迁移缺口，不能解释成 DSH 没有相应功能。Root、设备 ADB 控制、离线模型推理和开机自启动仍不属于已约定的本期范围；其他平台差异需要明确的适配与验收记录，不能静默删去原版行为。

Android 在模型工具分发边界守护 `read`、`read_image`、`write`、`glob`、`grep`、`edit`、`present`，以及动态加载的 `str_replace_editor`。会话工作目录和请求目标都必须实际解析到 App 自有工作区内。`read`、`read_image`、`write`、`edit` 和 `present` 可以使用相对工作区路径；`glob` 和 `grep` 也可以使用相对搜索路径或省略搜索路径。守卫为工具执行体固定会话目录并复查文件提供方的解析结果，避免稍后的会话目录变化重定向这些操作。原版 `str_replace_editor` 仍要求绝对文件路径；其目录查看暂不可用，因为原版两层遍历会跟随子级符号链接。新建目标只有在现存上级目录能够证明其仍在工作区内时才允许；无法确认的路径拒绝。这样可阻止模型通过普通文件工具读取工作区外的 App 私有账号和运行时文件，而可信 App 服务仍按各自权限访问。SAF 文档授权走 `android_files`，不能当作普通路径。`workspace-write` 本身只约束修改，不限制观察；此守卫是模型工具边界，并非对获批 Shell 或其他 App UID 代码的操作系统沙箱。主机夹具覆盖私有目录、符号链接和相似前缀拒绝，真机行为仍待验收。

## 构建预览版

使用 Windows PowerShell 7、Node 24、仓库指定的 pnpm、JDK 17、Android SDK 36、NDK 28.2.13676358、CMake 3.22.1，以及带 `aarch64-linux-android` 目标的 Rust 1.99.1。Flutter 与原生依赖版本固定在 [tool/runtime-lock.json](tool/runtime-lock.json)。先将指定 Flutter 版本放到仓库忽略的 `.cache/flutter` 目录，并配置 Android SDK。固定版本的 Android ripgrep 需在 Visual Studio Developer PowerShell 中按 [tool/ripgrep-android.md](tool/ripgrep-android.md) 构建。

完成 `pnpm install` 后，在仓库根目录执行以下命令。deploy 命令创建新的暂存目录；仅修改 App 时可保留该目录复用。依赖锁文件变化后应重新部署暂存目录。后面的 install 用于恢复 pnpm deploy 后的工作区开发依赖。

```powershell
pnpm.cmd run build:artifacts
pnpm.cmd --filter dsh-python-runtime-closure deploy --legacy --prod --config.allow-unused-patches=true --config.node-linker=hoisted --config.auto-install-peers=false --config.link-workspace-packages=true --config.hoist-workspace-packages=false .cache/android/runtime-bundle
pnpm.cmd install --offline --frozen-lockfile --prod=false --ignore-scripts
./apps/android/tool/build-ripgrep.ps1 -NdkDirectory "$env:ANDROID_HOME/ndk/28.2.13676358"
node node_modules/tsx/dist/cli.mjs apps/android/tool/stage-runtime.ts
./apps/android/tool/prepare-native.ps1
node apps/android/tool/smoke-runtime.mjs
./apps/android/tool/pack-runtime.ps1
```

原生准备脚本默认使用 `http://127.0.0.1:7897`；可通过 `-Proxy` 指定其他代理。脚本校验 Node 压缩包的哈希，以及 Android require-builtin 插件的源码版本。暂存运行时冒烟测试在电脑上执行，不代表 Android 兼容性已通过。

在 `apps/android` 执行以下命令。APK 输出到 `build/app/outputs/flutter-apk/app-debug.apk`，使用开发签名。如果本地网络需要代理，请配置 Gradle 的 HTTP/HTTPS 代理。

```powershell
../../.cache/flutter/bin/flutter.bat pub get
../../.cache/flutter/bin/flutter.bat analyze --no-pub
../../.cache/flutter/bin/flutter.bat test --no-pub
../../.cache/flutter/bin/flutter.bat build apk --debug --target-platform android-arm64 --no-pub
```

交付前，在本目录运行 `tool/verify-apk.ps1`，传入 `-ApkPath build/app/outputs/flutter-apk/app-debug.apk`，用 `-ExpectedVersionName` 和 `-ExpectedVersionCode` 指定本次构建的预期版本，并用 `-ExpectedRuntimeSha256` 传入独立打包的运行时哈希。校验器读取编译后的 Manifest 与 ZIP 条目，检查包括固定版本 ripgrep 可执行文件在内的十一个 ARM64 原生条目、上游许可资源，以及内嵌运行时与包内和可信 SHA256。还需运行 `node tool/verify-document-preview.mjs build/app/outputs/flutter-apk/app-debug.apk`，按资源清单与原模块哈希核对包内阅读器资源。两个校验器都以 JSON 输出结果，不一致时以非零状态退出。Gradle 的 `disable-abi-filtering` 属性保留应用明确设置的 ARM64 过滤；APK 文件名不能证明实际包含的架构。

## 运行时与存储

失败或关闭中的服务实例拒绝缓冲运行事件和新派发的原生工作；替换后的服务拥有独立生命周期。取消附件选择时，文件提供方的输入流在 Activity 线程之外关闭。取消不代表受阻塞的提供方已停止；复制工作线程负责清理尚未发布的文件。

替换就绪服务后，附件的旧上传凭据失效，已选文件保留供用户明确重试。文件页面撤下旧目录操作和分页游标；阅读页可以保留已显示文字，重新确认当前字节位置。文件搜索页保留查询，并将旧结果标为未核实。连接中断不代表搜索已经停止，重新连接也不会重复搜索。

SAF 文本分页携带文件版本。原生读取在复制前后核对文档标识与元数据；续页必须提交当前可见页的版本。文件变化时拒绝续页，避免把两个版本拼接，阅读页提供明确的重新开始操作。若提供方原地改写同长度内容且不更新上报元数据，这项检查无法发现。

App 重新连接时，一项独立状态读取失败不会阻断后续的会话、设置和任务读取。其他读取结束后仍会报告首项错误；连接被替换则停止旧连接的恢复流程。这些主机测试不能证明 Android 结束 Agent 进程后的真机恢复。

前台 Service 在 Node 启动后意外销毁时，会先记录运行时丢失结果，再终止专用 Agent 进程。计划内的插件服务切换在预留和最终提交时分别读取原版 Agent 注册表、输入队列、后台作业和插件操作状态；仍有任务或状态无法确认时拒绝切换，已经安全结束的工作可以继续切换。切换会清除运行标记，但在进程退出前继续持有租约，防止下一代在旧 Node 仍存活时启动；意外销毁时的启动锁也阻止并发启动越过收尾过程。下一次冷启动读取持久会话状态，不重放中断的模型流或等待授权的工具调用。最终 Node 确认后新任务启动仍有狭窄竞态，需设备级停机验收；Android 实际杀进程行为也仍需真机验收。

[APK 升级、离线与进程重启验收](tool/upgrade-offline-acceptance.md)使用两代真实 APK 包内的 Android 运行时，在主机上核对断网冷启动、联网恢复、已完成会话及不重复投递；系统安装升级、Keystore、SAF 授权和真机杀进程仍需单独验收。

前台服务在独立的 Android 私有进程中持有一个 Node 实例。Flutter 经 Binder 和专用本地套接字上的 JSON-RPC 通信，不使用本机 HTTP 服务。标准输出与错误写入私有运行日志，与协议通道分离。较大的 Binder 响应通过只读共享内存传递。打包运行时由名为 `android` 的 dsh profile 启动，工作区和会话存放在应用私有目录。API 凭据使用 Android Keystore 支持的加密存储；授权文档目录使用 Storage Access Framework 的持久授权。

“运行状态”页可发起一次原生隔离检查。Android `isolatedProcess` 服务只接收有限长度的只读文件描述符，并回报独立 UID、输入摘要及对另一应用私有标记文件的拒绝访问；服务连接变化后会清除旧结果。这只验证隔离基础，原版 PTC 和工作流执行器仍关闭，需完成授权文件与工具桥接、进程取消及真机验收后才能启用。

同一次诊断还会启动另一个独立隔离 guest，发送固定、有长度限制的 `diagnostic.echo` 帧。App broker 只允许一次回显调用，并核对调用者 UID、请求标识和最终响应；取消、超时及 guest 死亡只产生一个终态。这是通信探针，不是脚本运行时或通用工作流绑定，详见[guest 诊断协议](tool/guest-echo-diagnostic.md)。

隔离工作进程还可按单次请求读取由 App 授予的只读常规文件描述符，严格按 UTF-8 解码且最多 64 KiB；诊断时宿主会核对返回文字。App 侧的写回基础可在版本校验、取消检查后，将该受限文字原子替换到 App 指定私有工作区的直属文件并同步目录。桥接内的写回请求会串行提交，但其他同 UID 写入者仍可能在版本复核与替换间发生竞争；它尚未接入 PTC 或 Agent 执行。`node apps/android/tool/acceptance-isolated-worker.mjs` 在主机检查解码、写回边界和取消；Binder 取消与独立 UID 仍待真机验收。此桥接不接受模型输出的文件路径，也不执行 JavaScript。

Android 附件、会话和 ZIP 发布会先完整复制并同步临时文件，再通过原生 `renameat2(RENAME_NOREPLACE)` 发布，避开部分设备禁止的硬链接，同时不覆盖已有目标、不暴露未写完的文件。原版 DSH 的摘要、碰撞校验、租约和追加行为仍由原服务负责；其他平台保留已有发布实现。

Web 偏好与浏览器可修改的运行时设置分开。App 控制监听、范围和端口；网络回调选择明确的 Wi-Fi／以太网 IPv4 地址，局域网地址不可用时显示等待。服务失联时撤下访问链接，直到新的观察结果确认；迟到回执不能恢复旧地址或清除未保存的端口。凭证轮换保留 Agent 上下文。这些生命周期行为仍需 App/Web 共同操作的真机测试。

**网页搜索** 将搜索方式、服务参数和凭据引用合为一个原生流程。选择方式会同时调整搜索与网页读取服务；未知的自定义组合保持原样，直到用户明确更换。保存先检查各项原版配置的版本，再依次保存参数、凭据和服务选择。各项可能部分成功并立即生效；页面保留未解决的草稿，不自动重放结果未确认的写入。

Android Shell 工具通过原版 DSH 工具执行流程逐条请求授权，仅 `allowed-once` 允许执行；拒绝、取消及 `never` 授权策略都不会放行。命令使用应用现有 UID 和 Android 权限执行，不提供只读或仅工作区的操作系统沙箱。逐条审批是 Android 工具的规则，不代表桌面版默认策略。Root、ADB 控制、开机自启动和离线模型推理尚未实现。

会话资源页可打开由内嵌 Host 持有的 Android PTY。独立 ARM64 helper 确认每次输入和尺寸调整；Host 在页面重新进入时保留有上限的 xterm 屏幕，并在明确关闭或 Host 退出时回收进程。移动端页面投影带样式的字符格，限制可见行与样式段，并提供纯文本复制。实时输入按顺序发送输入法已确认的文字；写入失败时保留未确认文字，也保留手动发送的草稿模式。控制键与外接键盘发送 PTY 字节，方向键遵守应用光标模式。Host 通过有容量上限的队列回答支持的 xterm 查询与先前由程序设置的 OSC 颜色查询。程序的调色板和光标设置在重新进入页面后仍可恢复。[终端行为与剩余差距](../../docs/android-terminal.zh.md)列明这些限制。原版 Web 终端控制器仍被禁用，因为 APK 没有打包适用于 Android 的 `node-pty` 二进制文件。鼠标协议、完整 VT／OSC 行为、桌面停靠布局及真机 PTY／输入法验收仍未完成。

Shell 超时结果区分终止请求与命令已结束后才处理的截止定时器。截止时间会持续生效到输出管道关闭，因为 Shell 成功退出后仍可能有存活的后代占用管道。无法通过进程观察确认结果时，工具返回 `timedOut: null`、`timeoutStatus: "unconfirmed"` 及诊断信息，App 明确显示未确认。退出码为零本身不会清除超时标记，默认超时时长保持不变。

**授权与提问** 页面及 Android 通知与 Web 展示同一份 DSH 待处理请求。授权按钮发送原有的 `allowed-once` 和 `rejected` 结果。授权通知将提示与工具详情一并提供：Shell 详情使用实际工作目录和原始完整命令，其他工具使用原始参数，详情超过 3,500 个 UTF-16 编码单元时明确截断并提示进入 App 查看完整参数。简单问题可用通知选项或直接回复文字处理；复杂问题打开对应的 App 页面。计划审核问题使用独立的“批准计划”和“请求修改”操作；请求修改调用原版提问关闭语义，不会伪造选项答案。有工具调用标识的问题保持待答，可稍后返回；没有标识的问题以 `ASK_CANCELLED` 取消。等待、继续和取消由原问题控制器管理，通知投递令牌不会授予额外权限。旧通知或已回答请求不能重复作答。应用私有的预写标记也会在 Host 重启后阻止可能已提交的答复重复投递。原版授权决定或问题结果证明已结案后，冷启动核对会清除旧请求；仍待处理的 `started` 标记因无法证明送达而继续锁定。App 提供明确的停止当前任务入口，提醒先前工具操作可能已经发生；停止不保证清除原版中已延续的待答问题。App 提供系统通知权限与通知类别设置入口。

**后台任务** 展示原版 Agent 队列、待处理请求入口，以及记录的回合和子进程任务结果。取消操作停止当前回合并保留排队输入；移除队列项需要单独确认。停止请求成功后，界面会等待核心确认空闲才结束“正在停止”状态。缺失或尚未核实的历史会明确标注。子进程页面订阅原版任务目录及按字节游标续传的输出流，限制界面保留的输出量，并提供明确的停止请求。断线后，页面通过恢复的输出流核对未确认的停止结果；迟到回执不能覆盖新状态，只有用户可以再次发出停止请求。离开这两类页面不会取消任务。

**子 Agent** 在原生页面列出会话直接委派的子项，支持继续查看下级目录和分页历史，浏览不会启动或恢复 Agent。读取或控制有会话记录的子项时，使用直属父会话与子会话地址，由原服务校验。一次性子 Agent 和类型仍未知的子项只提供只读历史，外部条目不会获得伪造的会话历史。父会话可用时，可通过原版 `queue` 或 `steer` 操作向可续聊子 Agent 发送文本。原版父级中断操作停止当前回合并保留排队输入。提交结果未确认时，在当前 App 进程内保留草稿和请求标识，刷新与重连只读取状态，不自动重发；待确认草稿不能跨 App 进程终止保留。发送回执表示已接收，不代表工作已完成。

**后台执行** 展示前台服务的真实任务摘要、CPU 唤醒锁状态和系统电池限制，并提供 Android 应用设置入口。连接变化时立即撤下旧任务和唤醒锁状态，迟到的读取与设置回执不能确认新服务。结果未确认的设置会在当前页面内保留，供重新读取后比较，不会自动重发。可选的 CPU 保护使用有时限、可续期的唤醒锁，仅在核心最新状态表明 Agent 或后台作业正在工作时持有。只有等待回答或排队输入时不会持有；状态过期会释放保护并显示尚未确认。网络变化回调会合并，并在服务销毁时拒绝迟到回调。运行时传输失效时，独立 Agent 进程会停止，避免 Node 在无法展示状态或取消的情况下继续工作；再次启动只读取中断记录，不重放工作。服务停止前会同步写入 App 私有摘要，仅包含中断类别和时间；冷启动后后台任务页展示摘要，并提示用户核对原会话，不推断任务结果。摘要损坏或不可读取时会明确标记无法确认。系统报告前台服务超时也会停止该进程。Android Shell 由原生父进程死亡监督程序启动，Agent 消失时终止同组进程。Android 模拟器故障注入覆盖了关闭输出的后台后代；ARM64 真机行为及命令主动创建新会话的情况尚未验证。这些机制不能保证 Android 停止进程后任务仍能存活。

可选的**透明悬浮窗保活**默认关闭，开启前需要 Android 的“在其他应用上层显示”权限。服务仅在当前任务状态确认仍有工作时挂载一个物理像素大小、完全透明且不接收触摸的悬浮窗；任务完成、状态过期、权限撤销或服务结束时移除。设置页分别显示用户开关与实际挂载状态。Android 仍可能结束进程，而且完全透明的像素不满足 Android 15 后台启动前台服务豁免所要求的“可见悬浮窗”。进程死亡后不会为补偿而自动重放任务或工具。

任务摘要轮询超时或失败时，只要较新的推送状态仍在有限租期内，就不会提前撤销任务观察；租期届满仍会释放 CPU 唤醒锁和任务通知。重复的 `ready` 信号保留到期计时器。同一代际与版本却包含冲突计数的摘要会被拒绝，不会静默改写运行数量。这些状态转换已有主机测试，仍待真机验收。

Agent 任务确实成功完成时，可发出一条简短的 Android 通知并跳转到对应会话。通知从当前回合已记录的最后一条助手文本取最多 100 字的单句预览；没有正文时使用固定完成提示，不包含工具输出。通知标记为私密，锁屏上的展示由系统设置决定；用户正在查看该会话时不重复提示。同一会话有更新的完成记录时，尚未投递的旧通知会被撤下。Service 销毁时最多等待 250 毫秒让已接收完成事件的去重水位落盘，只投递已落盘的通知。进程突然终止或写入失败仍可能漏掉提醒；冷启动读取会话中已记录的结果，不会把历史完成事件当作新提醒或任务重放。失败、取消、历史中断与重新连接都不产生成功通知，通知权限和系统类别设置仍然生效。

**自动化任务** 使用原版任务目录、编辑、删除和投递记录。App 可筛选任务，修改活动任务的名称、指令和时间规则，并返回所属会话。创建入口打开对话，由 Agent 使用现有定时工具创建任务；App 不增加暂停或立即运行操作。编辑时比较原任务记录，发生冲突或结果未确认时保留草稿。投递记录表示提醒已到达会话，不代表模型执行完成。

Android profile 的 Host 冒烟测试还会通过模型工具创建短时一次性提醒，等待持久化投递记录，并核对任务结束前恰好有一条定时输入进入所属会话。测试成功后会删除其合成工作目录。这项主机测试不能证明锁屏或设备重启后的行为。

**聊天加号菜单** 遵循 DSH 的“添加”和“指令”分组及运行时实际指令目录。Android 当前禁用桌面沙箱权限预设，不伪造替代权限菜单。尚未配置凭据时也能创建会话、添加文件及使用不调用模型的指令。文件使用系统文档选择器和原版会话上传收据，上传失败保留所选文件以便重试。PNG、JPEG、WebP 和 GIF 通过 Sharp 官方 WASM 运行时使用原版图片校验、归一化和消息准入。图片发送仍受所选模型的输入能力限制。指令通过原命令服务执行。ZIP 导出使用原版会话日志格式和系统保存选择器。

在输入框开头输入 `/`，会在同一行内面板搜索当前会话的实际指令目录与技能。指令名和原版内建指令的中文标题按前缀优先的顺序子序列匹配；选择指令会消耗已输入的触发词，并沿用加号菜单的操作，选择技能则继续插入普通消息文本。指令目录读取失败会明确显示，技能候选仍可使用。提交已输入的指令时，仍按原版身份和附件规则解析；未匹配的斜杠文本仍是普通消息。手机面板尚未实现桌面 Web 菜单的方向键／Tab 选择、指令扩展装饰及持久的原版输入标签。此交互已有组件测试，但尚未在手机上验收。

所选图片和会话引用的图片可在原生缩放查看页打开，并提供重试和关闭操作。历史图片由原版会话服务校验访问权限，查看页不打开任意设备路径。预览另有 20 MiB 编码字节限制，并限制解码尺寸。预览失败不会删除草稿或改变原版上传限制。

历史文件附件可从会话打开原生阅读页。原版会话查询校验具体文件引用，附件存储完整验证内容后才提供临时副本。UTF-8 文本按段读取；其他格式提供系统另存为入口。保存会核对原始长度和 SHA256。连接变化后，已显示的文字标为未核实，不会重复保存；取消会等复制停止，失败会提示目标位置可能留下不完整文件。阅读与保存均不启动 Agent 或改变会话。

**对话展示** 按原版消息来源区分用户输入与注入的上下文。上下文和系统提示不进入普通阅读流，可在“会话记录”中查看。回复使用 GitHub 风格 Markdown 渲染，支持表格、列表和代码块。状态和失败事件显示为紧凑行；失败原因的首行直接可见，完整内容与诊断信息点开后查看。列表按需构建可见的对话项目并保留展开状态；流式回复使用原始调用尝试标识，区分重试内容。空白实时回复收到首段文字时，以仅重绘方式渐显且不推动布局；减少动画模式则立即显示。该入场行为已有组件测试，尚未经手机验证。

规划、思考与工具调用按原始回合合并成一条透明执行链。进行中的链默认展开；成功结束时自动收为一行“已完成”，之后仍可手动展开查看过程。失败、停止和未确认结果使用不同状态。展开后紧凑显示查询词、前两条来源、连续读取的网页和已记录的计划。完整工具输出仍在原有实时详情页查看，回复正文与复制操作保持独立。每个节点仍由列表按需构建。站点图标复用 Web 的域名映射和随包 Simple Icons 图形；未知站点显示网页图标，不联网请求 favicon。可运行 `node apps/android/tool/generate-site-marks.mjs` 重新生成图标，再格式化生成的 Dart 文件。

每条已完成回复的“更多”菜单可按该回复记录的 `turn/end` 序号，通过原版 `library.sessionFork` 服务创建新会话分支。来源有已保存标题时，新会话按原版编号规则递增标题。分支确认且历史读取成功后进入新会话；若打开或标题更新失败，App 会给出已创建的会话编号，供用户从“工作区与会话”找回。结果未确认或部分完成时不会自动重试。此回复操作已有主机测试，尚未在手机上验收。

Agent 进程被系统结束后，App 冷读取原版中断历史的投影，将已记录的部分回复和未知工具结果显示为中断；不会改写原始会话日志，也不会把工具结果冒称为成功。排队输入仍由原版核心保存，被结束的模型回合不会自动继续或重放。

会话列表读取按运行时连接代际隔离。旧连接请求尚未结束时，新连接可自行读取；迟到的旧结果或错误不能覆盖新列表。打开长会话时，历史分页期间收到的实时事件按序号合并，避免对完整历史反复线性扫描。

思考详情保持与预览一致的小字号。展开、折起均使用模糊与淡入淡出，流式更新不会重新播放。Markdown 删除线要求双波浪号，单波浪号表示的数值范围保留原文。发送消息后，新问题平滑上移，Agent 工作状态位于下方；底部留白随回复增多而缩减，用户拖动时停止定位。

**模型文件工具**使用原版 `read`、`write` 和 `edit` 实现及[文件系统沙箱提供方](../../packages/fs/fs-sandbox/README.zh.md)。Android profile 默认将修改限制在工作区和允许的临时目录，更宽范围的重试需要原版仅对本次调用生效的审批。覆盖或编辑已有文件保留原版已读取版本检查，编辑默认要求字面内容唯一匹配，明确选择 `replace_all` 时才替换全部。原 `fs-sandbox` 条目禁用，是因为 `android-filesystem` 继承该提供方。[Android 适配器](runtime/android-filesystem.mjs)通过已有的复制和排他重命名桥接发布新文件，替代硬链接，并保留原版版本检查和审批策略。[暂存 profile 冒烟测试](tool/smoke-file-tools.mjs)通过本地合成模型驱动真实主机文件操作、拒绝、取消和冷恢复。Android Binder 和设备文件系统验收仍未完成。该策略不会为 `android_shell` 提供内核级隔离，也不会恢复原版 `/permission` 菜单。

SAF 图片模型读取现在最多同时接纳两个提供方数据流。每个请求都有可取消的标识；在接纳前收到取消请求就不会开始读取，撤销授权或 Service 关闭会取消进行中的读取。读取器满额时会在打开其他提供方数据流之前明确提示稍后重试。[主机请求生命周期检查](tool/acceptance-document-image-requests.mjs)覆盖这些状态转换；实际提供方取消行为与内存表现仍需真机验收。

**执行权限**设置页读取运行时实时提供的策略快照，区分原版文件工具沙箱模式与 Android Shell 的默认策略：隔离执行器就绪前不向模型注册命令工具。明确启用的内部迁移模式保留每次获批的 App UID Shell，并标明它不受隔离。运行时连接变化会使旧观察结果失效；页面可以进入待处理授权请求，但不会提供虚构的预设开关。Shell 命令实现独立约束前，原版权限预设服务继续禁用；该页面不证明设备 UID 行为，也不等于迁移了原版 `/permission` 指令。

**沙箱与执行权限**页面显示面向模型的程序工具边界尚不可用：只读、没有可写路径、网络关闭。[Android 沙箱策略](tool/android-sandbox-policy-design.md)将文件授权、网络目标和审批分开。目前已有受限的文件与 HTTPS 能力代理、正式 Android DNS 解析器，以及只接受 Agent 进程调用、可按策略使用可选宿主调用的[内部隔离 JavaScript 执行器](tool/isolated-script-run.md)。它还没有模型可见的调用方。[Shell 隔离门禁](tool/shell-isolation-gate.md)现默认在审批和启动进程前拒绝调用，普通模型工具中不注册 `android_shell`；只有明确启用的内部迁移模式保留未受隔离的 App UID 执行器用于诊断。PTC 与工作流执行仍禁用，等待接线和设备验证。

**通用设置**将原版共享的 `ui-settings.enabled` 偏好显示为原生开关，而不是 JSON 字段。Host 配置经确认后才可操作，写入携带文档版本；回执确认前继续显示已接受的选择。重连或写入结果不确定时必须重新读取并由用户明确核对，不自动重发。已确认的值控制工作区改动、会话轨迹入口和内置未命名 PTC／极简预设的展示，不构成工具权限。如果关闭后默认值仍是未定制的内置 PTC／极简预设，App 会通过原版带版本检查的设置服务有条件地改选健康的标准预设。已定制、未知或已经变化的默认值留给用户人工核对。原版其他通用设置项及首次引导仍待迁移。

当 Host 提供 `session-log-deepseek` 时，通用设置也会在安装版本上方显示原版 Session Log 上传开关。它展示已接受的值，并携带 Host 文档版本保存修改。只读或缺失的配置不可修改；结果不确定时需要重新读取、明确核对，不会重发写入。仅有这个控件不能证明 API 请求实际上传了日志。

**授权文件** 支持单文件、目录、分段 UTF-8 读取及撤销授权，SAF 访问仍为只读。App 与 Agent 共用持久 SAF 授权范围内的字面文本搜索，可选择区分大小写，并限制读取量、遍历范围和执行时间。结果标明跳过的文件与未完成的搜索；不完整结果为空不代表没有匹配。取消操作等待原生搜索实际结束，文档授权不会将 `content://` URI 转成 Shell 路径。

点选 PDF、图片等非文本文件时，App 把对应 SAF `content://` 文件交给 Android 应用选择器，并仅授予本次读取权限。普通文本和源码继续使用内置阅读器；阅读器也提供“在其他应用中打开”。私有工作区与会话文件只在用户点选后，把单个普通文件暂存到 App 缓存（上限 256 MiB），通过不可导出的 `FileProvider` 提供临时读取权限，不暴露整个私有目录。会话文件使用原版会话范围内的文档接口分段读取，复制期间文件变化会被拒绝。离开文件页面会取消准备，独立的启动确认步骤阻止迟到的应用选择器。此入口只读，在外部应用中编辑不会写回 DSH。取消或 Activity 结束时清除尚未交出的副本；启动与每六小时的维护会清除超过 24 小时的文件，并将缓存控制在 512 MiB 以内。Android 也可能提前清理缓存。设备上可接收的应用及选择器外观仍需真机验收。

当前搜索结果可在原授权范围内打开源文件，也支持单文件授权。阅读页检查当前访问权限并从文件开头显示；搜索行号不会自动定位阅读位置。返回后保留查询和结果，不重新扫描。连接变化后尚未核实的旧结果需重新搜索后才能打开。

**工具活动**按原始回合和步骤配对调用与结果，包含嵌套 PTC 调用。紧凑行打开可拖动的详情面板，展示记录的命令、独立的 stdout 和 stderr、退出码及超时状态。复制操作保留完整记录值，运行时截断仍明确提示。原行滚出屏幕或分组折叠后，面板继续跟随该调用更新；切换会话或调用离开已加载历史时关闭。同一已知回合的连续调用可以折叠显示，但不合并记录或改变 PTC 归属。缺失结果、失败和中断保持区分，Agent 空闲不代表工具已有结果。长按消息可打开 FlClash 菜单，复制正文，或进入原生页面选择部分文字。

**会话模型** 区分当前选择和待应用草稿，显示明确的勾选标记及模型专属推理选项。空白会话继承原版目录默认值，已保存但暂不可用的模型仍保持可见。App 在编辑前初始化会话，订阅原版模型投影，应用前检查变更，应用后回读服务归一化的结果。失败保留草稿，结果不确定时先核对再重试。原版 `selectModel` API 没有原子比较并交换操作；这些检查可以发现已观察到的冲突，不能阻止检查与写入之间的所有并发覆盖。

推理强度使用紧凑的中文滑动档位，包含独立的“默认”选项。服务确认实际模型与强度后，App 才按会话保存该选择；观察到不同选择或目录默认值变化时，旧记录失效。保存偏好失败与模型切换结果分别提示。

模型目录和首页模型入口对准确匹配官方 DeepSeek Flash 的条目显示原版仅用于展示的 `1017` 角标。两处均读取真实 Loader 清单，仅在该插件明确启用且运行时显示；缺失、失败和状态未确认时不显示。不改模型名称或请求路径。主机与组件测试覆盖状态投影，设备显示仍待验收。

**Agent 预设** 原生设置页展示原版预设目录、默认选择、加载失败原因和只读声明。新会话入口与会话模型页可查看该会话实际使用的预设。预设页打开时仅读取状态，不会创建或恢复会话。原版服务仅允许在第一轮开始前切换预设；默认值变更影响后续新会话。默认值修改使用原版设置版本检查，失败或结果不确定时保留草稿且不自动重发。Android 当前只提供一个受支持的本地预设，此页面不会启用桌面专属能力。

Android 预设原样组合原版文件系统技能提供方、技能调用、待办和文件交付工具，不替换它们的配置。主机上的[可移植工具冒烟测试](tool/smoke-preset-portable-tools.mjs)使用 Android profile 和本地测试模型，验证发现、调用、并行待办状态、文件存在性校验、持久事件及冷读取不重放。

**技能**可从聊天菜单和消息开头的 `/` 建议进入。选择技能插入普通 `/name` 文本；发送时保留原版命令优先级和技能注入。可搜索列表包含仅用户可调用的技能，提供方给出的文件路径使用会话阅读器打开。预设变更、插件操作和重新连接会使目录失效。[目录冒烟测试](tool/smoke-skill-catalog.mjs)验证冷读取不激活 Agent、不改写日志，以及原版仅用户调用流程。已发送消息只高亮其记录批次中确认注入的技能名。专属技能行根据原始调用和结果显示名称、状态及说明文本，当前目录不会改写历史。点击引用打开当前提供方文件，点击工具行则查看记录的输出。[重放与组件测试](test/chat_skills_test.dart)覆盖这两种动作；其真机验收仍待完成。

**文件、目录和会话引用**通过输入框的 `@` 选择器调用原版候选服务。点击目录插入引用，点击旁边的箭头浏览下级。选择保留原始路径写法或规范会话引用。查询变化、页面销毁和原生客户端断开会取消待完成查询，连接替换后拒绝旧结果。已发送消息使用原版 UTF-16 匹配规则和记录的会话标签，文件引用打开来源会话的阅读器。目录和会话标签不提供点击动作，与原版会话正文一致。[原生选择器](lib/chat_references.dart)、[查询通道](runtime/reference-discovery.mjs)和[正文引用](lib/chat_user_references.dart)已有针对性主机回归；手机验收仍未完成。

**待办和交付文件**使用原版持久事件。悬浮待办摘要保留并行项目，可打开记录的清单，并在新一轮开始时清空。已结束轮次的交付卡保留准确路径，同路径采用最后一次声明，通过同一会话阅读器打开。主机组件测试覆盖恢复、更新和大字号布局；这些新控件仍待真机验收。

**文件变更**显示原版已结束轮次的摘要，并打开原生差异页面。App 与 Web 共用 `ui-settings/enabled` 设置，只有原服务返回非空摘要后才显示卡片。差异比较轮次开始和结束时捕获的内容，打开当前文件是独立动作。捕获内容不会跨服务重启持久保存，日志中保留通知不表示差异仍可读取。无 Git 工作区的原版文件操作捕获不包含任意 Shell 修改。[原生变更处理](lib/workspace_changes.dart)、[差异回归测试](test/workspace_diff_test.dart)和 [Android profile 主机冒烟测试](tool/smoke-workspace-changes.mjs)覆盖限定会话的读取、取消、重启限制及会话日志不变；Android 真机验收仍未完成。

**子 Agent 模型选择** 使用原生可搜索列表，按提供方和模型的准确标识选择。提供方暂不可用时仍显示已保存的选择。关闭功能会保留列表；开启时至少选择一个模型。开关和列表通过原版设置 API 及版本检查一并保存，影响新会话。冲突时保留当前配置和草稿，供用户核对。

**账号与配置** 页面使用原版账号和模型服务。登录在 Android Custom Tab 中打开官方授权页，临时回环监听器仅处理授权回调，不会启用 Web。完成页的 `dsh://open` 链接返回原生账号页，不携带凭据、不改变登录状态；登录结果由原版账号服务确认。登录成功后调用原版默认模型初始化规则；初始化失败保留已登录账号，并提供独立重试。个人资料、余额和通知独立加载，模型／服务商凭据及默认值有原生编辑页面。异步模型错误显示在对应会话中，重连后仍可查看。

实时模型目录读取失败时，模型页仍读取本地服务商配置与已保存的默认模型。同一连接和账号观察版本下，上次成功读取的目录会以明确标注的只读内容显示；服务进程或账号状态变化后不会拿旧目录代替新状态。目录恢复前不允许修改默认模型；页面打开期间有限次自动重试，也保留手动刷新。目录读取失败时，不能据此判定已保存的模型目前可用。原版模型服务的远程列表缓存只在进程内；离线冷启动会使用该版本内置的账号模型，授权是否有效仍由原版凭据服务判定。

自动生成的配置页在连接变化时保留草稿，包括无效的表单或 JSON 输入。保存使用原版脱敏设置 API 和版本检查，保留受保护的凭据。写入结果未确认时暂停再次提交，通过只读核对检查当前值；版本变化本身不表示写入失败。带修改离开页面需要明确选择，采用当前设置会放弃草稿且不重发写入。

用户覆盖值待撤销时，原生开关与选择项会预览原版配置描述中的实际继承值。保存仍只删除用户覆盖，不会把预览值另写为新设置。受保护的值仍不展示，没有默认值的字段也不会凭空变成关闭状态的开关。

**插件管理**使用原版清单、操作和回执。APK 包含锁定版本的 pnpm 与核心包归档，Android 从已提取的原生库目录执行 Node 命令。主机测试覆盖本地安装与共用 Cordis 解析；设备安装、生命周期脚本和第三方兼容性仍需验收。包操作单独计数，不混入 Agent 回合或后台作业，计数涵盖等待锁、应用变更与回滚。维护切换必须先在运行中的核心取得同步预留，才能保存模式或停止进程；存在包操作或状态未知时拒绝切换，预留释放或进程退出前不接受新的包操作。

维护切换还计入 App 已接受、但仍在等待会话创建、附件解析或原版消息提交的请求；最终确认前会重新检查。预留期间拒绝新的 App 会话提交与子 Agent 消息。主机测试覆盖预留前后两种时序。Web 或扩展直接发起的 Agent 请求仍依赖最终的原版 Agent 与作业快照；完整进程退出竞态还需真机验收。

账号观察与模型目录由 App 运行实例持有，在当前进程内关闭页面后仍保留。返回前台时重新核对服务连接和读取订阅，不重发写入操作。账号断连时保持待确认状态，同时展示上次读取的资料；标记为过期的模型目录必须刷新后才能打开编辑页。认证状态仍以原版 DSH 凭据服务为准，这些展示缓存不会另存一份令牌，也不能授权账号操作。

返回前台时也会重新连接被系统回收的 Android 服务。多个恢复请求共用有时限的连接握手，按保存的模式启动服务、注册新客户端，再读取真实运行状态后恢复订阅。Binder 已连接不代表 Node 已就绪。旧连接的迟到回执会被丢弃，中断的操作不会重新执行。恢复过程保留 Web 偏好，不替换账号凭据。

**凭据引用** 列出当前设置结构声明的引用，以及用户在 App 中明确输入的引用。模型与工具的同名引用共用原版凭据服务。页面只读取配置状态和可写状态，不读取已保存的密钥或账号记录。替换和移除操作在结果未确认时保留请求归属，页面导航和重连不会重放写入。未保存的密钥输入在本次 App 进程内跨页面保留，进程退出后不保留。

**运行设置导入导出** 分为选择操作、导入内容、变更预览、应用结果和导出预览。系统文档选择器读取或保存 JSON。设置使用易读名称及分组行，文本详情在独立页面中显示，并保留原始标识和版本。导出只提供保存文件，导入则先展示所选变更再应用。它通过原版设置服务迁移受支持的普通设置。秘密字段与凭据、Web 控制、设备授权、主题、插件拓扑及受保护的 Android 运行设置不在范围内，因此不是完整备份。未知或无效字段会阻止导入，省略的字段保留当前值。每个命名空间使用原版版本检查，多个命名空间可能部分成功。App 逐项显示结果，遇到冲突或写入结果未确认时停止，保留源文本供核对，不自动回滚或重放。高级 JSON 编辑仍然保留。

替换导入草稿使用统一确认弹窗。取消弹窗或文件选择器均保留原稿，重复确认不会打开多个选择器。普通状态与说明文字不提供文字选择控件，明确的 JSON 查看页仍保留。

**诊断** 区分服务启动或故障与账号状态尚未确认。活动订阅诊断仅展示接口名称、投递阶段及已接收序号，不包含请求参数、响应内容和传输标识。复制或刷新这些观察结果不会重试业务操作。诊断页可明确请求重启服务进程，界面等待实际就绪事件后才报告恢复成功。设置页从原生应用元数据读取实际安装版本和构建号，提供加载、失败与重试状态，不使用写死的版本文字。

**启动配置与恢复** 即使 Node 无法启动，也能使用原生通信。进入维护模式会中断当前工作，等待原服务进程退出，并核对残留的应用进程后才允许写入；进程检查不完整时保持只读。App 编辑 Android 与全局的 `cordis.patch.yml`，以及 Android profile 的 `package.json`，不编辑自动生成的根配置。保存会比较原文件哈希，保留原字节或“不存在”状态的私有备份，并记录操作回执。恢复“不存在”的备份会明确移除当前文件。冲突和未知结果保留草稿，不自动重放。保存时验证 UTF-8、大小和清单 JSON 语法；完整配置是否有效，由随后原版 DSH 的实际启动验证。

恢复首页展示服务状态及配置、备份、操作记录和运行资源修复入口。进入维护、恢复备份与修复资源使用统一确认弹窗；恢复“不存在”状态时明确询问是否移除当前文件。服务或运行资源版本变化后，原来的恢复或修复确认失效。操作列表使用易读名称，请求标识保留在技术详情中。

恢复页面可预览备份、查看私有运行日志末尾的 64 KiB，并隔离当前内嵌运行资源缓存，以便从已安装 APK 重新解包，不会重置会话、凭据或文档授权。实际服务模式与下次启动偏好不同时，会分别显示。维护模式会保留到用户在 App 中明确恢复正常运行。普通插件激活前，Android profile 的配置组合检查会拒绝替换必要宿主条目或开启静态 Web 监听器的用户配置；可执行扩展仍是应用代码，不是受到沙箱隔离的配置。

**私有工作区文件** 通过原生只读页面浏览 App 默认私有目录。目录分页和 UTF-8 文本分页在继续读取前检查文件变动。图片、PDF 与 Office 文件可经明确的 App 私有作用域进入内置文档阅读器；读取限制在私有根目录内，复核文件身份与版本，并分别限制整文件、字节窗口和 Office 输入大小。此流程不借用会话的文件权限。文件名与字面内容搜索显示跳过项及受限、未完成的结果，不跟随符号链接。此入口不接受任意设备根目录，也不替代 SAF 授权。浏览和搜索限制可在 Android 工具设置中调整；文档字节上限目前属于运行时配置。
