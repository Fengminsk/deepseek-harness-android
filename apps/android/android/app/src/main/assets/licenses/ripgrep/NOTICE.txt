The Android arm64 executable in this application is built from the pinned
source with Rust 1.99.1 and Android NDK 28.2.13676358. The executable is
named libpocket_ripgrep.so so Android will install it into its executable
native-library directory; it is invoked as a process rather than loaded as a
JNI library.
